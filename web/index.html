时间状态首字总耗时估算 tok/s输入 / 输出
这些数据能说明什么？

首字延迟从原生请求发出计至首个文字块到达，包含网络、排队和推理等待；首个可见事件还可能是推理摘要。这里测的是客户端体验，不是服务端纯计算耗时。

估算生成速度 =（输出 Token − 推理 Token − 1）÷ 首字至完成的秒数，每 Token 耗时为其倒数。一个文字块可能含多个 Token，因此两者均为估算；少于 32 个可见 Token、缺少分项、重试或路由变化时不提供该估算。端到端输出效率 = 含推理的输出 Token ÷ 总秒数。块间隔用于观察停顿，不冒充逐 Token 间隔。

降速提示仅比较同模型、连接、档位、探针类型、输入/输出量级及缓存比例类别；近期 5 次对比此前 5–10 次，首字中位数增加至少 50% 且 0.5 秒，或估算速度下降至少 30% 才提示。不能据此证明限速、模型降级或服务方意图；速度变化不参与暂停/恢复。

输入 Token/s 不能从本地记录还原为服务端输入处理速度。用量减少也不能单独证明“省 Token”；需同时比较相同任务的完成质量。本面板按各来源保留的最近 80 条、近 7 天统计；导出含最多 30 条明细，不含提示词与回答正文，保存到本地运行数据目录的 exports 文件夹。
